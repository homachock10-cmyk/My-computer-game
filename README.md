# My Computer Game

A small pixel-art room simulator that runs directly in a web browser.

## How to play
- Open `index.html` in a browser, or enable GitHub Pages for this repository to publish it.
- Move with **WASD** or the **arrow keys**. On phones, use the on-screen arrows.
- Walk near the computer and press **E** to work and earn coins and experience.
- Use the shop to upgrade the computer and decorate your room.
- Progress is saved in your browser using local storage.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then save. After the site is published, open the Pages URL shown there.
